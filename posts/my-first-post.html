My First Post

2026-09-01

Hello! This is my first post on this site. I built a small system so that I can keep adding writings without touching the listing page manually — each post is just an HTML file, and the Writing page picks it up automatically from a manifest file.

How it works

Everything is static. There are three pieces:

  • posts.js — a list of all posts (title, date, file, links).
  • writing.html — reads that list and renders it.
  • posts/<slug>.html — one HTML file per post, like this one.

To publish a new post I just copy the template, write my content, and add a single entry to posts.js. That's it.
